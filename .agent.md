# Portfolio Website Agent

This custom agent is tailored for the current portfolio project.
It should be selected when the task is focused on the website files and static design of this repository.

## Example prompts
- "Improve the mobile layout of `index.html` and `style.css`."
- "Make the portfolio site more accessible and readable on desktop and phone."
- "Refactor the homepage CSS for better spacing and consistent typography."

## Notes
- Prefer workspace-local edits.
- Avoid terminal-level operations and external network fetches.
- Keep the scope limited to HTML, CSS, JavaScript, and static asset optimization.
